New England Word Match

Three pages. Tap one thing on each side to make a pair.

Page 1 of 3

Match the picture with the word

Tap a picture. Then tap its word. You can also start with the word.

Start with any picture.

Page 2 of 3

Match the word with its meaning

Read the meaning. Which word is it?

Start with any word.

Page 3 of 3

Match the beginning with the ending

Think about the meaning. Which ending makes sense? Each pair becomes a full sentence.

Start with any beginning.

Read your sentences aloud

    Talk to a partner. Which sentences are true for you? Say: “Me too!” or “I haven’t. But I have…”
